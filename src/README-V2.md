# Edwin CV Portfolio v2

## Main improvements

- Bilingual professional positioning aligned with the official IT Services Specialist role.
- GitHub integrated in the top navigation and contact profile.
- Stronger explanation of the stolen-device application, Scrum collaboration, regulatory context, and technical-reference responsibilities.
- Professional capabilities separated into technical, leadership/collaboration, and communication/growth categories.
- Competency values capped at 99 and supported with practical evidence.
- New Engineering and Data Vision section connecting enterprise applications, cloud, data engineering, analytics, and the ongoing Data Science Master's studies.
- New Professional Growth section emphasizing cloud/backend growth and active English development.
- Modular data files under data/en and data/es.

## Installation

Replace the current `src` contents with the contents of this package, preserve `public/profile.jpg`, and run:

```bash
npm install
npm run dev
```
