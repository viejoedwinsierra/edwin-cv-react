# CV data structure

Each language has independent files so you can update one section without editing a large monolithic file.

- `meta.js`: language buttons and interface labels.
- `profile.js`: personal profile, contact, summary, languages, interests, and section titles.
- `skills.js`: full technology list.
- `competencies.js`: technical, leadership, and communication indicators.
- `platforms.js`: backend, frontend, database, cloud, DevOps, and runtime groups.
- `projects.js`: supported project names.
- `experience.js`: professional experience timeline.
- `education.js`: academic education.
- `certifications.js`: certifications and additional training.

Update both `es/` and `en/` when changing translated content. `src/data/index.js` combines both languages for the application.
